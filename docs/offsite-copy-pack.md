## 8. 完成後的回填動作（重要！建立交叉連結網）
每登錄一個平台、拿到該頁 URL 後：
1. 加進官網 `src/seo.config.ts` 的 `ORG_SAME_AS`（一行；會自動進首頁 Organization JSON-LD）。
2. 用 `scripts/wikidata-enrich.ts` 把對應 property 補進 Wikidata：
   - LinkedIn 公司頁 → **P4264**（LinkedIn company ID，URL 中 `/company/<這段>`）
   - Crunchbase → **P5995**（permalink）
   - Facebook → **P2013** / X(Twitter) → **P2002**
3. `npm run deploy` 上線官網改動。

> 這一步是把「站外提到你」與「你的官方實體」綁成一張可被 LLM 追蹤的網——比單純登錄更關鍵。
